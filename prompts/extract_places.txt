You are extracting route places from a historical travel text written in Chinese or mixed Chinese/English.

Return places in the order they are encountered in the text. Focus on geographical entities relevant to the traveller's route: settlements, gates, bridges, mountains, rivers, temples, ferries, roads, passes, lakes, administrative places, and named landscape features.

For each place:
- preserve the exact original written form in original_name;
- give a conservative normalized_name only when normalization is obvious; otherwise repeat the original name;
- preserve the date/day phrase if present;
- quote the shortest source sentence that supports the extraction;
- classify route_role as exactly one of: passed, mentioned_only, passed_and_mentioned;
  - passed: the traveller physically passes, visits, stays at, departs from, or arrives at the place;
  - mentioned_only: the place is discussed or named but is not part of the traveller's physical route;
  - passed_and_mentioned: the place is both physically encountered and separately discussed or referenced;
- infer place_type conservatively;
- infer historical_region only when supported by the text/context; otherwise null;
- confidence must be between 0 and 1.

Do not invent coordinates. Do not collapse separate visits that occur at different positions in the route. Do not silently add places that are not in the text.

Return exactly one JSON object with a top-level "places" array. Each item must contain route_order, original_name, normalized_name, date_text, sentence, route_role, place_type, historical_region, and confidence. Use null for unknown optional values and do not wrap the JSON in Markdown.
